# Portfolio 2026

Modern, animated portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- 🎨 6 dynamic themes (3 light, 3 dark)
- ✨ Smooth animations with Framer Motion
- 📱 Fully responsive design
- ♿ Accessible components
- 🚀 Fast and optimized

## Tech Stack

React • TypeScript • Vite • Tailwind CSS • Framer Motion
